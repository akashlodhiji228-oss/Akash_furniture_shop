# Akash Furniture Shop

A modern, responsive web application for a furniture shop built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- **Frontend Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript
- **Backend/API (if applicable):** Express, Google GenAI

## 📋 Features

- Interactive product categories section
- Smooth, high-performance animations with Framer Motion
- Clean and modern user interface
- Fully responsive design

## 🛠️ Installation & Setup

1. **Clone the repository** (if not already done)
2. **Install dependencies:**
   Make sure you are in the project root directory, then run:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:3000` (or the nearest available port).

## 📁 Available Scripts

- `npm run dev`: Starts the development server using Vite.
- `npm run build`: Bundles the app for production.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs TypeScript type-checking without emitting files.
- `npm run clean`: Cleans up the `dist` folder and server-related files.
